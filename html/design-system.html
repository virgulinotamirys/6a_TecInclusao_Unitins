Design System

Guia de referência visual do projeto Conecta Futuro — cores, tipografia, espaçamento e componentes usados no minicurso de HTML e CSS.

Paleta de cores

Definidas como variáveis CSS em :root, dentro de style.css. Usar sempre a variável (var(--cor-primaria)), nunca o valor hexadecimal direto, mantém a página inteira consistente.

Primária --cor-primaria: #2563eb
Primária escura --cor-primaria-escura: #1e3a8a
Secundária (destaque) --cor-secundaria: #f59e0b
Texto --cor-texto: #1f2937
Texto claro --cor-texto-claro: #6b7280
Fundo --cor-fundo: #ffffff
Fundo alternativo --cor-fundo-alt: #f3f4f6
Borda --cor-borda: #e5e7eb

Tipografia

Uma única família de fonte para toda a página, com uma escala pequena de tamanhos — o suficiente para diferenciar títulos e texto, sem criar inconsistência.

--fonte-base: "Segoe UI", Roboto, Arial, sans-serif

Esta é a fonte usada em toda a página, do título ao rodapé.

h1 · --tamanho-h1: 2.5rem (40px)

Título principal

h2 · --tamanho-h2: 1.75rem (28px)

Título de seção

h3 · --tamanho-h3: 1.1rem (17,6px)

Subtítulo / título de card

texto · --tamanho-texto: 1rem (16px)

Texto normal de parágrafo, usado no corpo da página.

Espaçamento

Escala baseada em múltiplos de 8px. Usar sempre um valor da escala (em vez de números soltos, como 13px ou 22px) mantém o ritmo visual da página.

--espaco-1: 0.5rem (8px)
--espaco-2: 1rem (16px)
--espaco-3: 1.5rem (24px)
--espaco-4: 2rem (32px)
--espaco-5: 3rem (48px)
--espaco-6: 4rem (64px)

Outros valores

Pequenos ajustes usados em conjunto com cores e espaçamento.

Raio de borda --raio-borda: 8px
Largura máxima do conteúdo --largura-maxima: 1100px
